LIFELINE AI — EMERGENCY INFORMATION RESCUE SYSTEM
Student project prototype

FILES
- index.html: website structure
- style.css: layout and visual design
- script.js: form logic and missing-information checks
- README.txt: instructions

OPEN ON YOUR COMPUTER
1. Extract this ZIP file.
2. Open the LifeLine_AI_Prototype folder.
3. Double-click index.html.

PUBLISH WITH GITHUB PAGES
1. Open your GitHub repository.
2. Upload index.html, style.css, and script.js directly to the repository top level (root), not inside another folder.
3. The file name must be exactly index.html in lowercase.
4. Go to Settings > Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Choose branch main and folder /(root), then click Save.
7. Wait a few minutes. Use Visit site in Settings > Pages when the URL appears.

IMPORTANT
This is a front-end educational prototype. It does not use a real AI model, collect GPS coordinates, access live traffic/crowd information, save data to a server, or contact emergency services. The missing-information checker uses simple browser-side rules.
For a real emergency in India, call 112. Do not delay contacting emergency services to complete this form.
